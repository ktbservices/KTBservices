# KTB Services website

Standalone React + Vite + Tailwind version of the public KTB Services website, prepared for GitHub + Cloudflare Pages.

## Build

```bash
npm install
npm run build
```

Cloudflare Pages settings:
- Framework: Vite / React
- Build command: `npm run build`
- Output directory: `dist`

This public site does not include the Base44 authentication pages/backend. The KTB homepage components are kept as React source.
